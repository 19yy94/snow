# Melty Snow Duo

눈사람 듀오가 악당들을 눈덩이로 얼려서 굴려 쓸어버리는 협동 플랫폼 액션 게임.
9개 스테이지 + 보스(불꽃 드래곤).

## 실행
`index.html` 하나로 돌아가요. 브라우저로 열거나 GitHub Pages에 올리면 바로 플레이 가능.

## 조작
- ← → 이동
- ↑ 점프
- SPACE 눈 던지기
- P 일시정지 · Enter 다시하기
- 모바일은 화면 아래 터치 버튼

## 참고
온라인 2인 모드는 claude.ai 아티팩트의 실시간 방 기능을 써서, 깃허브 등 다른 곳에서 열면 비활성화돼요(혼자 하기는 정상 동작).
